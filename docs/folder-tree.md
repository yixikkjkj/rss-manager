# 统一文件夹树与三栏阅读

桌面阅读器按左侧资料库、中间列表、右侧正文排列；正文占主要宽度。树节点通过菜单完成文件夹和订阅源管理，独立的源管理和收藏夹页面已移除。宽度不超过 850px 时通过三个面板按钮切换，避免挤压正文。

## 数据与行为

- `t_folder.parent_id` 表示父文件夹，`t_feed.folder_id` 表示订阅归属；一个源只属于一个目录，根目录用 NULL 表示。`t_article_folder` 保留多文件夹收藏关系。
- 选中文件夹时，查询合并其自身及所有后代的活跃源文章、收藏文章，并按文章 ID 去重。源节点只列出该源文章。
- 树上的未读数采用相同的子树范围；已读状态由文章共享。当前文章自动已读时保持列表行和位置，重新筛选或刷新时应用未读条件。
- 文件夹同级名称唯一，跨目录可同名。最多 64 层；移动检查整个子树高度、环路与用户归属。删除包含活跃子文件夹或源的目录会返回错误。删除叶目录移除收藏关联，不删除文章。
- 删除源后，历史文章仍可通过收藏目录或搜索访问；普通源列表不再显示已删除源的文章。
- 新建、重命名、移动均在树菜单中完成。源菜单还提供设置、测试、重试、删除；在设置里更改所属目录即可移动源。

## 路由与组件

`/?folder=…`、`/?feed=…`、`/?unread=1` 表示列表范围，`article` 表示右侧文章，`page` 表示列表页码。`Reader` 订阅路由变化，保持树和列表实例，正文按文章 ID 重建。展开状态保存在 sessionStorage，前后篇和返回列表保留当前阅读上下文。

旧 `/article/:id`、`/folders`、`/feeds` 和 `?group=…` 链接会进入新阅读器。搜索结果进入阅读器后，中列保留关键词、排序、日期与分页范围。

前端仍使用 Lit Light DOM；布局、文件树与正文样式由 Rspack 编译 SCSS Modules 并提取 CSS。

## 迁移与接口

新增 `0003_folder_tree.sql`，启动时事务迁移到 schema v3。保留原收藏夹 ID；活跃旧分组分别迁为根目录文件夹，重名添加“订阅分组”后缀。`t_legacy_group_folder` 保存旧 ID 对照以兼容书签，旧分组表和列仅保留为迁移记录。重新启动不会重复迁入。

文件夹创建增加 `parent_id`；新增 `folder_move`。订阅、文章及搜索筛选使用 `folder_id`。`article_read_all` 替代旧 `group_read_all`，可限定文件夹子树或订阅源。旧 `group_*` RPC 已移除，前后端需一起构建和升级。

OPML 保留完整文件夹路径和空文件夹，重复导入复用同级目录和已有源，不移动已有源。OPML 不包含文章内容、阅读状态或收藏关联，这些通过 SQLite 备份保留。
