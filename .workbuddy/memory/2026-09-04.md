### 冻结的技术决策（后续开发直接沿用）
- 技术栈：Rust(Axum) + SQLite(FTS5/WAL) + React 18 + TypeScript + Zustand + rspack；前端 rust-embed 编译期内嵌，单二进制
- 接口风格：全 POST + JSON，RPC 显式功能名 `/api/rpc/*`（不用 REST path/query/form param）
- 部署：单用户自托管；二进制 与 Docker 双态（Docker 推荐）；数据默认 `/data/`（可配）；交付物 = 配置文件 + 构建脚本（Dockerfile/docker-compose/Caddyfile/.env.example/build.sh）
- 反向代理：Caddy v2（ACME 自动 HTTPS，443 TLS 终结，转发 127.0.0.1:8080）
- 访问控制：仅应用层登录（argon2id，≥12 位）+ 可选 IP 白名单（方案 A）
- MVP 范围：F1–F14（含 Readability 全文抓取 F13 + 收藏夹 F14）；per-feed 抓取间隔（全局默认+单源覆盖，下限 ≥30min）
- 数据模型：users 表 + user_id 全表预留（单用户）；收藏夹 = folder（t_folder/t_article_folder）
